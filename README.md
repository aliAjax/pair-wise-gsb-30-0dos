# 油品配送 · 司机当班排程台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

1. **待发单三要素**：派单时记录司机、发车时间、预计用时。
2. **时段不重叠**：同一司机新排行程不得与既有行程、强制休息时段重叠。
3. **4 小时驾驶红线**：累计（自上次休息起）驾驶满 4 小时前必须先休息 30 分钟；
   相邻两趟间隔 ≥30 分钟视为已休息，累计清零。单趟不得超过 4 小时。
4. **按当班时段派单**：司机资料含班次（支持跨零点，如 14:00–02:00），发车/收车必须落在当班窗口内。
5. **改派 / 释放留痕**：改派或释放时释放原时段，把原因和旧完成时间写入该单历史；校验不通过的单留在**待安排区**，不占用任何时段。
6. **本地持久化**：重开页面仍可见占用时段、休息安排（时间轴斜线块）与待安排单。

## 分层结构（司机资料 / 排程判断 / 本地保存分开）

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 司机资料 | `src/data/drivers.ts` | 司机、车辆、班次（静态，不参与存储与判断） |
| 初始数据 | `src/data/seed.ts` | 首次打开的演示订单 |
| 排程判断 | `src/lib/schedule.ts` | 纯函数：重叠、班次、4 小时休息规则、时间轴推导 |
| 时间工具 | `src/lib/time.ts` | 本地时间格式化 / datetime-local 转换 |
| 本地保存 | `src/lib/storage.ts` | localStorage 读写（key：`hxwlfront-19-driver-schedule`） |
| 状态编排 | `src/store/schedule.ts` | Pinia：派单 / 改派 / 释放 / 流转，每次变更后持久化 |
| 界面 | `src/components/*.vue`、`src/App.vue` | 排程台、待安排区、已排程列表、派单弹窗 |

时间轴中：蓝色=待发车，绿色=运输中，灰色=已到站，橙色斜线=30 分钟强制休息，红色=休息不足/冲突。
